# ⚡ LanChat — 无中心、默认隐身、极低内存占用的跨平台局域网互传工具

专为拥有多台本地设备（**macOS / Linux / Windows / iOS / Android**）的个人或小团队打造的轻量级局域网即时消息与文件流式共享工具。

---

## ✨ 核心特性

1. **🔒 默认隐身（零广播）与开关可控发现**
   - 启动时**绝不主动发送任何公开 UDP 广播**，未授权的局域网设备扫描不到、也无法访问页面。
   - **两种配对方式**：
     - **隐身直连（无需开广播）**：直接复制本机左上角的 `IP:Port#6位配对码` 在另一台电脑粘贴完成双向绑定。
     - **限时开放发现开关**：手动点击界面上的「允许被发现（3分钟）」，倒计时结束后自动恢复隐身。
   - **信任设备静默重连**：配对成功后交换 Ed25519 公钥与 256-bit 共享密钥；即使后续路由器 DHCP 改变了某台设备的 IP，也仅通过 50 字节全混淆 HMAC 签名包静默寻址。

2. **🧠 纯内存环形池（严格水位线上限，退出即焚）**
   - 聊天记录与剪贴板图片仅保存在内存 [`RingBuffer`](internal/store/ringbuffer.go) 中，**不落盘历史记录**，进程关闭瞬间彻底清空。
   - **双重水位线保护**：默认最多保留 **200 条记录** 且内存池总体积不超过 **20 MB**（可通过 `-max-mem` 与 `-max-msgs` 调节），超出时自动按 FIFO 淘汰最早记录并立刻释放内存。

3. **🚀 64KB 固定缓冲流式文件直传（零内存膨胀）**
   - **拖拽上传流式转发**：从浏览器或手机拖拽多文件发送时，采用固定 **64KB 滑动窗口**边流式接收边计算 `SHA-256`，不把文件读入内存。
   - **本机大文件零拷贝直传**：在桌面端点击「⚡ 本机大文件零拷贝直传」并输入磁盘路径（如 50GB 的镜像或视频），0 字节复制、1 毫秒发布，其他设备点击下载时直接从原路径流式拉取。

4. **📱 手机端免装 App（扫码即用 PWA）**
   - 启动后终端直接打印 Unicode 二维码，或在网页点击「📱 手机扫码」，iOS / Android 相机扫码即可全屏访问移动版界面并支持「添加到主屏幕」。

## 🛠️ 编译与运行（使用 Conda 环境中的 Go）

### 1. 运行单元测试与多节点集成测试
```bash
/Volumes/T9/test/envs/monitor/bin/go test -v ./...
```

### 2. 编译当前系统单文件可执行程序
```bash
make build
# 或者直接执行：
CGO_ENABLED=0 /Volumes/T9/test/envs/monitor/bin/go build -ldflags="-s -w" -o lanchat .
```

### 3. 一键交叉编译全平台单文件（Mac / Linux / Windows）
```bash
make build-all
```
产物位于 `dist/` 目录，拷贝到对应系统的机器上即可直接运行（**100% 零外部依赖**）。

## 🚀 启动模式与命令行参数

```bash
# 1. 默认模式：启动并自动打开默认浏览器进入界面
./lanchat

# 2. 桌面提醒/独立应用窗口模式
./lanchat --tray

# 3. 静默后台守护模式（不自动弹浏览器，适合开机自启或无桌面 Linux）
./lanchat --daemon

# 4. 自定义端口、设备名与内存池上限（例如限制内存池最大 10MB、最多 100 条消息）
./lanchat --port 52520 --name "My-Linux-Workstation" --max-mem 10 --max-msgs 100
```
